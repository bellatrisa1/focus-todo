## 🧭 Что умеет Focus

| Для чего               | Возможности                                                          |
| ---------------------- | -------------------------------------------------------------------- |
| **Записывать**         | Название, описание, три приоритета, необязательные проект и срок     |
| **Планировать**        | Разделы «Сегодня», «Предстоящие», «Просроченные» и «Избранное»       |
| **Организовывать**     | Проекты, фильтры статуса, поиск по названию, описанию и проекту      |
| **Выбирать главное**   | Сортировка по сроку, приоритету, алфавиту и дате создания            |
| **Двигаться по шагам** | До 30 подзадач, независимые отметки выполнения и индикатор прогресса |
| **Видеть результат**   | Счётчики, процент завершения и карточка фокуса на сегодня            |
| **Сохранять**          | Автосохранение, обновление других вкладок, экспорт и импорт JSON     |
| **Исправлять ошибки**  | Подтверждение удаления и отмена последнего удаления                  |

Интерфейс полностью на русском языке. Он адаптируется к телефону и компьютеру, поддерживает клавиатуру, явные подписи полей, сообщения валидации и возврат фокуса после закрытия диалога.

> 💡 Срок означает календарный день. Просроченной считается незавершённая задача со сроком раньше сегодняшней даты на устройстве. Выполнение всех шагов не завершает родительскую задачу автоматически: финальное решение остаётся за вами.

## 🚀 Быстрый старт

Требуется **Node.js 20.9+** и npm. Локальные проверки выполнялись на Node.js 22.

```bash
npm ci
npm run dev
```

Откройте **http://localhost:3000**.

Для production-сборки остановите dev-сервер, затем выполните:

```bash
npm run build
npm start
```

Ключи API, аккаунт и база данных для запуска не нужны.

## ⌨️ Быстрее с клавиатурой

| Клавиша                    | Действие                      |
| -------------------------- | ----------------------------- |
| `N` в английской раскладке | Открыть новую задачу          |
| `/`                        | Перейти к поиску              |
| `Enter` в поле шага        | Добавить шаг                  |
| `Esc`                      | Закрыть диалог                |
| `Tab` / `Shift + Tab`      | Перемещаться между элементами |

Глобальные сочетания не срабатывают при вводе текста или внутри диалога.

## 💾 Ваши данные

Focus — **локальное приложение**: задачи хранятся в `localStorage` текущего браузера под ключом `focus-todos-v1`. Данные задач не отправляются на сервер приложением. Хранилище привязано к адресу сайта: другой домен, порт или браузер имеет отдельный набор задач.

- После перезагрузки задачи восстанавливаются автоматически.
- Новые поля совместимы с прежними копиями Focus версии 1.
- Изменения появляются в других открытых вкладках того же браузера через событие `storage`.
- При одновременной записи из двух вкладок побеждает последняя запись; полноценного разрешения конфликтов нет.
- При повреждённых данных или запрете чтения приложение работает в памяти и не перезаписывает исходное хранилище.
- При ошибке записи изменения остаются в памяти, а интерфейс предупреждает о риске потери после перезагрузки.
- Очистка данных браузера удаляет задачи. **Регулярно сохраняйте резервную копию.**

### 📦 Резервные копии

Откройте **«Резервная копия» → «Скачать копию»**. Полученный JSON содержит задачи, проекты, шаги и статусы.

Для восстановления выберите JSON-файл и подтвердите добавление. Импорт проверяет формат, добавляет только новые ID и сохраняет существующие задачи. Это объединение данных: импорт не обновляет задачи с совпадающими ID. Максимальный размер файла — **5 МБ**.

Файл содержит ваши названия и описания без шифрования. Храните его там, где вам удобно и безопасно.

Отмена удаления восстанавливает удалённые задачи, сохраняя последующие изменения. История отмены находится в памяти и сбрасывается после перезагрузки или получения изменений другой вкладки.

## 🎨 Визуальный стиль

Спокойная светлая палитра, фиолетовый акцент, карточки проектов и дневной фокус. Логотип объединяет круг концентрации, знак выполненного действия и маленькую точку роста.

- [SVG-логотип](public/focus-logo.svg) — масштабируется без потери качества.
- `src/app/icon.svg` — иконка вкладки браузера.
- `src/components/Logo.tsx` — компонент логотипа в интерфейсе.

## 🛠️ Архитектура

```text
public/
  focus-logo.svg           # Логотип для использования вне приложения
src/
  app/                     # Страница, layout, метаданные и favicon
  components/              # Общие Icon, Logo и Modal
  features/todos/
    components/            # Workspace, Sidebar, TodoForm, TodoItem, Backup
    schemas/               # Валидация формы, задач и резервных копий
    store/                 # Zustand, сохранение, синхронизация и unit-тесты
    types/                 # Типы задач, фильтров и сортировки
  lib/                     # Поиск, сортировка и календарные даты
  styles/                  # Глобальные стили и визуальные токены
tests/                     # Пользовательские сценарии Playwright
```

**Состояние.** Zustand централизует изменения задач и сохранение. Список вычисляется через чистый selector и `useMemo`. Формы используют React Hook Form и Zod; состояние диалогов остаётся в React.

**Загрузка.** Сервер и первый клиентский рендер показывают одинаковое состояние загрузки. Чтение хранилища выполняется из `useEffect`; до его завершения изменения задач блокируются. Загрузка ничего не записывает, поэтому пустой начальный массив не стирает сохранённые данные.

**Формат.** `{ version: 1, todos }`; ID создаются через `crypto.randomUUID()`. Служебные даты записываются в UTC ISO, срок хранится как `YYYY-MM-DD` без пересчёта часового пояса. Фильтры и поисковый запрос не сохраняются.

## ✅ Проверки

```bash
npm run typecheck
npm run lint
npm run format:check
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Unit-тесты проверяют CRUD, валидацию, поиск и сортировку, календарные разделы, избранное, шаги, отмену удаления, импорт и ошибки хранения.

Браузерные тесты выполняются в desktop и mobile Chromium: создание и редактирование, сохранение после перезагрузки, фильтры, поиск, подтверждение удаления, клавиатура, проекты, шаги, скачивание копии, импорт, отмена и обмен изменениями между вкладками.

Playwright самостоятельно собирает приложение в **`.next-test`** и запускает production-сервер на **`127.0.0.1:3108`**. Он не использует текущий dev-сервер на порту 3000. Снимки и трассировки находятся в `test-results/`. Mobile Chromium проверяет мобильный размер и взаимодействия, но не заменяет проверку Safari на настоящем iPhone.

## 🌱 Границы версии

Эта версия завершает сценарий личного локального планирования. Облачные аккаунты, синхронизация между устройствами, командная работа, повторяющиеся задачи, push-напоминания, тёмная тема и установка как PWA пока не реализованы.

Для облачной версии понадобятся серверное хранилище, авторизация, резервное копирование и разрешение конфликтов. Эти возможности не имитируются в интерфейсе.
